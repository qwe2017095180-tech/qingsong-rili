        想自己手动配？展开 macOS / Windows 命令行教程
        

          
手动配置步骤

          

            
            
          

        

        

          
    
            
  1. 保持电脑版微信（WeChat 4.x）处于已登录状态。
    2. 
            
  2. 确认本机已有微信解密读取技能（默认目录 ~/.dsh/skills/wechat-decrypt，含 .venv 与密钥文件）。
    3. 
            
  3. 如首次读取报权限错误，在「系统设置 → 隐私与安全性 → 完全磁盘访问权限」中勾选终端或轻松日程，重启后再点上方「实测读取微信」。
    4. 
            
  4. 如刚更新微信或换账号导致新消息读不到，可在终端重新提取一次本机密钥：
              
    
                cd ~/.dsh/skills/wechat-decrypt && .venv/bin/python scripts/macos/extract_key.py
                
              
    
            
    5. 
          

        

        

          
    
            
  1. 确认已安装 Node.js 18+、Python 3.9+，且 Windows 版微信 4.x 已登录。
    2. 
            
  2. 在项目 vendor\wechat-decrypt 目录初始化一次 Python 依赖：
              
    
                cd vendor\wechat-decrypt && python -m venv .venv && .\.venv\Scripts\python.exe -m pip install -r requirements-windows.txt
                
              
    
            
    3. 
            
  3. 用管理员权限打开 PowerShell 提取一次数据库密钥（会重启一次微信）：
              
    
                .\.venv\Scripts\python.exe scripts\windows\extract_raw_key.py 30
                
              
    
            
    4. 
            
  4. 执行全量解密到明文库（日后同步新消息时再次运行即可）：
              
    
                .\.venv\Scripts\python.exe scripts\windows\decrypt_all.py
                
              
    
            
    5.
