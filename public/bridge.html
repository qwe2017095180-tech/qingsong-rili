连接轻松打卡

开启后，同一 Wi-Fi 下的手机上的轻松打卡可以读取这里的待办和截止事项，放进「今日日程」；在手机上添加的日程也会同步回来变成待办。只开放日程，不开放聊天内容和设置。

手机端步骤
  1. 手机和这台电脑连同一个 Wi-Fi（校园网如果隔离设备，可改用手机热点给电脑上网）。
  2. 打开轻松打卡 → 底栏「更多」→「轻松日程」。
  3. 填上方的电脑地址和配对码，点「测试连接」。
  4. 回到首页，「今日日程」里就能看到今天截止的事项，点 ＋ 添加的日程会同步过来。

macOS 第一次开启时，如果弹出「是否允许 node 接受传入网络连接」，请选「允许」。
